## ⚠️ 重要声明

本程序已使用 **Windows 自签名证书**（CN=Web CP Tools, O=k20120509）签名。

由于是开发者自签证书，**首次下载**在部分电脑可能触发：
- Windows SmartScreen 拦截
- 360、电脑管家、火绒等误报

### 解决方案（任选其一）

1. **安装签名证书（推荐）**：解压 → 双击 `webcp_signing.cer` → "安装证书" → 选"受信任的根证书颁发机构" → 完成
2. **添加白名单**：在杀毒软件中将 `website_cloner.exe` 加入信任列表
3. **临时关闭杀毒软件**：运行前关闭 360/电脑管家/火绒等

## 快速开始

### 第一步：下载和解压

1. 访问 [GitHub Releases](https://github.com/k20120509/web-cp/releases/tag/V16.0)
2. 下载 `website_cloner_v16.0.exe`
3. 放到任意文件夹（如 `D:\Tools\WebCloner\`）

### 第二步：安装签名证书（必做）

1. 双击 `webcp_signing.cer` 文件
2. 点击"安装证书"
3. 选择"本地计算机" → 下一步
4. 选择"将所有的证书放入下列存储" → "受信任的根证书颁发机构"
5. 点击"下一步" → "完成"
6. 重启电脑（或刷新系统缓存）

### 第三步：运行程序

1. 双击 `website_cloner_v16.0.exe`
2. 阅读欢迎界面提示
3. 输入 `y` 确认已阅读文档
4. 选择是否初始化代理池（建议选 y）
5. 选择爬取模式，输入网址，开始使用！

## 详细使用教程

### 3.1 简单打包模式（推荐新手）

适用于大多数网站，可选择爬取深度（1-12层）。

```
是否初始化代理池用于加速？(y=是/n=否，默认n): y
正在初始化代理池...
代理池就绪！最优: 1.2.3.4:8080 (延迟 0.52s)

请选择模式:
  1. 简单打包 - 可选择爬取深度(1-12)
  2. 全面打包 - 全自动裂变爬取(深度999,页面9999)
选择 [1/2]: 1
请输入爬取深度 (1-12): 3
目标网址: https://example.com

开始克隆: https://example.com
深度: 3, 页面上限: 300
代理: 开启
输出目录: E:\cloned_example_20260728_120000
```

**深度说明：**
- 深度 1：只克隆首页
- 深度 2：首页 + 首页的链接
- 深度 3：首页 + 链接 + 链接的链接（推荐）
- 深度 5-12：更完整的克隆（耗时更长）

### 3.2 全面打包模式（高级）

适用于需要完整克隆的网站，自动爬取所有链接。

```
选择 [1/2]: 2
目标网址: https://example.com

开始克隆: https://example.com
深度: 999, 页面上限: 9999
```

**注意：** 此模式会爬取大量页面，可能耗时很长。建议先用简单模式测试。

### 3.3 克隆完成后

程序会自动：
1. 在资源管理器中打开克隆结果目录
2. 显示统计弹窗（成功率、总大小等）
3. 询问是否继续爬取其他网站

## 功能特性

### 1. 智能进度条

- 预扫描确定总任务数
- 进度只增不减，不会倒退
- 实时显示下载速度、剩余时间
- 超时自动完成（防止卡死）

### 2. 代理加速（V16.0 新增）

- 自动获取、测试、选择最优代理
- 支持外网网站克隆加速
- 菜单选择是否启用

### 3. 动态页面渲染

- 使用 Playwright 渲染 JavaScript 动态页面
- 模拟用户滚动，触发懒加载图片
- 等待网络空闲后保存

### 4. 资源本地化

- HTML/CSS/JS/图片/字体 全部下载到本地
- 自动重写资源路径为本地路径
- CSS 内的资源引用也会被处理

### 5. B 站视频下载

- 自动检测页面中的 B 站视频链接
- 后台下载视频到 `_videos` 目录
- 支持多清晰度选择

### 6. 断点续传（资源下载）

- 中断的资源下载支持重试
- 失败的链接自动回刷

## 常见问题解答

### Q1: 克隆进度卡在 100% 不动？

**A**: V16.0 已修复此问题！新增了超时机制：
- 总爬取时间超过 10 分钟自动完成
- 连续 60 秒无进展自动标记完成
- 进度条会显示"[超时完成]"提示

### Q2: 克隆的网页是空的或内容不完整？

**A**: V16.0 改进了内容获取：
- 降低了 HTML 长度阈值（从 500 字符降到 100 字符）
- 即使内容很短也会保存
- 自动回退到动态渲染模式

### Q3: 被目标网站限流？

**A**: V16.0 优化了请求策略：
- 请求间隔从 0.005s 增加到 0.05s（10倍）
- 重试次数从 10 次降到 3 次
- 添加随机延迟避免规律访问
- 降低并发数（从 64 降到 32）
- **建议：** 初始化代理池可以有效避免限流

### Q4: 克隆的网站如何本地查看？

**A**: 
1. 打开克隆输出目录
2. 双击 `index.html`
3. 所有资源已本地化，离线可访问

### Q5: 如何卸载/清理？

**A**: 
1. 删除 `website_cloner_v16.0.exe`
2. 删除克隆结果文件夹
3. 删除临时文件
4. 如需移除证书：
   - 打开"运行" → `certmgr.msc`
   - 找到"受信任的根证书颁发机构"
   - 删除 `Web CP Tools` 证书
